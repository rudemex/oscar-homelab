# Proxmox

## No abre UI

- ping;
- SSH;
- puerto 8006;
- servicios proxy/daemon;
- filesystem lleno;
- certificados/hora;
- bridge.

## VM sin red

- bridge asignado;
- VLAN tag;
- NIC virtual;
- DHCP/reservation;
- firewall Proxmox/guest;
- switch port/trunk.

## I/O alto

Identificar VM/job responsable, backups concurrentes, storage casi lleno o salud de disco.
