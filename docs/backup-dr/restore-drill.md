# Pruebas de restore

## Mensual

Restaurar un archivo o configuración seleccionada al azar.

## Trimestral

Restaurar una VM/servicio importante en red aislada.

## Semestral

Simular pérdida del host principal sobre papel o hardware alternativo y recorrer dependencias:

1. red;
2. Proxmox;
3. storage;
4. DNS;
5. core services;
6. datos;
7. workloads.

Registrar tiempo real. El objetivo es descubrir documentación ausente antes de un incidente.
