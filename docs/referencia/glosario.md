# Glosario

**ADR** — registro de una decisión arquitectónica y sus consecuencias.  
**GitOps** — operación declarativa donde Git representa el estado deseado.  
**LXC** — contenedor de sistema usado por Proxmox.  
**RPO** — cuánto dato podemos aceptar perder medido en tiempo.  
**RTO** — cuánto tiempo aceptamos tardar en recuperar.  
**SLO** — objetivo medible de nivel de servicio.  
**VLAN** — segmentación lógica de capa 2.  
**Workload** — aplicación/proceso que ejecuta la plataforma.  
**Blast radius** — alcance potencial de un fallo o cambio.  
**Drift** — diferencia entre estado declarado y estado real.
