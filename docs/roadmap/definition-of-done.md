# ¿Cuándo un servicio está terminado?

No cuando “abre en el browser”.

- [ ] instalación reproducible;
- [ ] versión definida;
- [ ] owner/propósito documentado;
- [ ] IP/DNS/puertos registrados;
- [ ] datos persistentes identificados;
- [ ] secretos fuera de Git;
- [ ] backup implementado si corresponde;
- [ ] restore probado si los datos importan;
- [ ] healthcheck/monitor;
- [ ] logs accesibles;
- [ ] recursos observables;
- [ ] upgrade procedure;
- [ ] rollback procedure;
- [ ] runbook básico;
- [ ] exposición de red mínima.
